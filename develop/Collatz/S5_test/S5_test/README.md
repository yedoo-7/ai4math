1. 文档的强归纳只对 `n` 是 S5 的情形完成了归纳步骤，但其归纳假设"所有小于 n 的正奇数收敛"要求对每一个正奇数（含 S1/S3/S7）都证出收敛；对 S3/S7 数有 `collatzT n = (3n+1)/2 > n`，其轨道在首次进入 S5 前可远超 `n`，无法用"值更小"的归纳假设处理。
2. 论证隐含依赖"从任一 S5 数 n 出发、首次回到 S5（或到 1）时的值小于 n"这一断言；我用计算机枚举验证此断言为假——在 `n < 200000` 内即有 3240 个反例（例如从 n=109 出发首次回到 S5 的值是 445 > 109）。

#
三条证伪结论保持不变并继续成立：
- `collatzT_not_S5_closed`：压缩映射不保持 S5 类（反例 `T(109)=41`）。
- `collatzT_expands_S3_S7`：对所有 S3/S7 数 `T(n) > n`。
- `first_S5_return_can_exceed`：存在 S5 数（`n=109`），其轨道首次回到 S5 的值（`445`）大于 `n`。

## 结论
"所有 S5 数收敛到 1"这一条**单独**是可以严格证明的——前提是允许加一个合适的假设。原因是：仅凭定理 2（S5 的一步收缩）无法闭合归纳，必须补一个关于"轨道如何下降"的假设；只要这个假设到位，第二部分就是一条干净、可机器验证的归约。

## 为什么定理 2 一条不够
定理 2（强制收缩）说：对 S5 数 n，`T(n) < n`。这是初等可证的（无条件成立）：`n%8=5 ⟹ 8 ∣ 3n+1 ⟹ 2³ ∣ 3n+1`，故 `3n+1` 的奇数部分 `≤ (3n+1)/8 < n`。
但 `T(n)` 虽然更小，**通常不再是 S5**（例如 `T(109)=41`，41%8=1）。于是想对 S5 做强归纳时，归纳假设落不到 `T(n)` 上——你被甩进 S1/S3/S7，而对 S3/S7 反而有 `T(n)>n`，轨道在首次回到 S5 前可能升过 n（如从 109 出发首次回到 S5 的值是 445>109）。这正是原"强归纳"证明的逻辑缺口（已在 `Part3Refutation.lean` 中形式化证伪）。所以**必须**补一个提供"严格下降量"的假设。

## 需要哪些步骤（即 `Part2Strong.lean` 的结构）
1. 定义：压缩映射 `T(n)=ordCompl[2](3n+1)`（`3n+1` 的奇数部分）；`S5` 即 `n%8=5`；`Converges n := ∃k, T^[k] n = 1`。
2. 合适的假设 `part1Strong`：**任意非 S5 的奇数 m>1，有限步内进入某个严格更小的 S5 数**（`∃k, (T^[k] m)%8=5 ∧ T^[k] m < m`）。这就是"S1/S3/S7 会进入一个更小的 S5"。
3. 定理 2（强制收缩）：S5 数 n 有 `T(n)<n`。
4. 辅助引理：`T` 保持奇性、迭代保持奇性（`collatzT_odd`/`collatzT_iterate_odd`）；迭代值收敛则原值收敛（`converges_of_iterate`）。
5. 对全体正奇数做强归纳 `all_odd_converges`，三种情形：
   - `n=1`：0 步收敛；
   - `n` 是 S5：用定理 2 得 `T(n)<n`，对更小的奇数用归纳假设；
   - `n` 是 S1/S3/S7：用 `part1Strong` 得到严格更小的 S5 数，再用归纳假设。
   每步都落到严格更小的奇数，强归纳闭合。
6. 推论 `collatz_thm3_S5_converges`：所有 S5 数收敛到 1（S5 是上面结论的特例）。

## 关于"合适的假设"
- 关键在于把第一部分从"进入某个 S5"**强化为"进入某个更小的 S5"**——多出来的"更小"正是强归纳所缺的良基下降量。有了它，归约干净可证；没有它（只有定理 1+定理 2），"S5→1"等价于完整考拉兹猜想，属公开未决。
- 另一种同样自然的、范围更窄的替代假设：只谈 S5——"每个 S5 数 n>1 的轨道终会回到一个严格更小的 S5 数（或 1）"，然后**只对 S5 做强归纳**即可直接得到 S5→1，连 S1/S3/S7 都不必提（变体）。

简言之：**能证**，步骤就是上面的 1–6；唯一不可省的是一个提供"严格下降"的下降型假设（把第一部分强化为"进入更小的 S5"），其余全是初等且已验证的归约。


强化前提（`part1Strong`）的陈述：对任意 `S1/S3/S7` 数 `m`（奇数、`1 < m`、`m % 8 ≠ 5`），存在步数 `k` 使得 `collatzT^[k] m` 是 `S5` 数（`% 8 = 5`）**且严格小于 `m`**。这正是"S1/S3/S7 会进入某个更小的 S5 数"。

在此前提下，第二部分可以干净地证出来。关键定理：
- `collatz_thm2_forced_contraction`（定理 2，强制收缩）：对任意 S5 数 `n`，`collatzT n < n`。
- `all_odd_converges`：对所有正奇数 `n` 做强归纳证明收敛。归纳步骤分三种情形——`n=1` 直接收敛；`n` 是 S5 时用定理 2 得 `collatzT n < n`，再用归纳假设；`n` 是 S1/S3/S7 时用强化前提 `part1Strong` 得到一个更小的 S5 数 `collatzT^[k] n < n`，再用归纳假设。因为每一步都落到一个严格更小的奇数上，强归纳得以闭合。
- `collatz_thm3_S5_converges`（定理 3，S5 收敛定理）：作为推论，所有 S5 数收敛到 1。

辅助引理 `collatzT_odd`、`collatzT_iterate_odd`（保持奇性）、`converges_of_iterate`（迭代值收敛则原值收敛）均完整证明。

错误的本质：对数值 `n` 做强归纳，归纳假设是"所有小于 `n` 的正奇数收敛"，却只对 `n` 是 S5 的情形完成了归纳步骤。一个对全体正奇数的强归纳要成立，必须对每个奇数（含 S1/S3/S7）都完成步骤；只做 S5 一种情形，归纳无法闭合。这一缺口体现为三个可证伪的隐含断言，文件逐一形式化并证明其为假：

1. `collatzT_not_S5_closed`：压缩映射 `T` 不把 S5 类映回 S5 类（反例 `T(109)=41`，`41%8=1`）。所以把强归纳限制在 S5 类上时，归纳假设根本覆盖不到 `T(n)`。
2. `collatzT_expands_S3_S7`：定理 2 的"收缩"`T(n)<n` 是 S5 独有的；对所有 S3/S7 数反而有 `T(n)>n`。所以"由 `T(n)<n` 加归纳假设即收敛"的模式对非 S5 奇数根本不成立，缺口补不上。
3. `first_S5_return_can_exceed`：存在 S5 数 `n`，其轨道在首次回到 S5 之前会升过 `n`——从 `n=109` 出发首次回到 S5 的值是 `445>109`（含"中间各步都不是 S5"的首次性证明）。这直接证伪了文档隐含依赖的"轨道不升过 `n`/首次回到更小"的断言。

综合 1–3，定理 3 的强归纳证明是错误的（其推理依赖的隐含断言均为假）
