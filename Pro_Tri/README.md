- 每题用到的前置知识（三角形内角和、正弦定理、余弦定理、面积公式、射影定理、
  中线长公式、半角公式、正三角形面积、割补法、向量垂直条件等）统一**集中声明在
  namespace 之前**，作为本题的“公理 / 前置定理”。
